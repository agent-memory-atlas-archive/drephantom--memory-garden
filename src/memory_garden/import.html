1. 留下一段微信聊天

把你主动复制的聊天文本粘贴到这里，无需安装导出工具。请保留原有发言人和完整日期时间；缺少时不要凭记忆补写。

支持带时间和姓名的文本，也支持已有的微信 Chatlog JSON。纯正文不能自动还原发言人或日期；这里只保存你提供的片段，不是完整微信历史备份。

输入暂留在本页，点击预览后才交给本机服务解析；确认导入前不加入记忆。

1. 连接本机的 QQ 记录

这是可选的外部客户端连接，需要你另行安装并登录 QQChatExporter。本项目没有内置或安装它；已有导出文件可直接使用“导入文件”。

只将你选中的会话送入本地预览。上游工具可能预读更多记录；这里展示最近的有限条数，不是完整历史备份。访问令牌不写入配置或浏览器存储。

连接前，了解外部工具的权限

QQChatExporter / NapCat 会接触账号会话及聊天数据，开源和本机运行不等于经过安全认证。我们的本机地址限制不能约束它自身的权限或监听范围。请先核对安装来源、版本和访问配置；本项目只做接口适配，尚未真实账号联调。微信可通过文件或粘贴入口导入，尚未直接读取客户端。

1. 选择一个导出文件

支持 .txt、.json、.md，单次不超过 2 MiB、2,000 条消息。图片、语音和压缩包暂不解析。

支持怎样的文本格式

需要保留发送时间、说话人的名字和消息正文。若导出工具的格式暂不支持，请不要删掉这些信息后强行导入。

2024-01-02 09:30:00 我
今天重新看了以前写下的想法。

2024-01-02 09:31:00 朋友
可以一起回看。

自动识别也支持微信 Chatlog JSON、QQChatExporter JSON 和 ChatLab 标准 JSON。通用 JSON 可使用带 sender、timestamp、text 字段的消息数组。导出文件中的角色和时间会在下一步展示。

点击预览后，文本会发给当前本地服务解析。预览与导入均不调用云端模型，也不改动你的原始文件。
