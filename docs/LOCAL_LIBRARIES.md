# 连接本地 Obsidian 笔记库

页面上的「连接笔记库」按钮可输入本机文件夹的完整路径，或切换到已经连接的库。
选择 Obsidian Vault 的根目录，例如 `D:\Notes\My Garden`；不用复制笔记到项目目录。

连接成功后立即打开全局图，不需要重启。每个库有独立的索引、对话、聊天导入与确认记忆，
浏览器草稿也按库区分。切回旧库可以继续之前的对话。连接失败时保留原来的库；
有回答或其他操作正在执行时，先完成该操作再切换。

## 数据与模型

- 原始笔记只读。索引和聊天等派生数据保存在应用的数据目录中，不能把该目录当作原始笔记备份。
- 导入处理 Markdown 笔记，跳过 Obsidian 配置、回收站、模板及既有排除项。不会通过目录链接读取 Vault 外的文件。
- 新库默认本地关键词检索，生成模型、云端 Embedding 与 Rerank 不会继承演示库的权限。
- 需要模型对话时，在当前库的设置中配置并开启；设置页会说明问题、历史和选中片段的发送范围。
- 未连接模型时，页面和每条回应会标明本地模式。普通讨论会提示连接模型，不会默认搜索私人笔记或套用“观点变化”的结论；明确查找与回看仍可在本地进行。
- 修改笔记后，可在设置页点击「更新本地索引」。目前没有后台文件监听。

## 图的范围

全局图是当前允许检索的索引。普通双链与 Markdown 链接形成可核对的连线，独立笔记也保留。
全局最多显示 500 个节点与 3,000 条边；超出会显示省略量，可用搜索找到其他记录。
图不会凭标题相似、共同标签或模型猜测自动创造连线。
