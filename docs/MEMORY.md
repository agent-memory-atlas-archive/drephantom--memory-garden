# 对话、记忆与修正

## 普通交流与回看记录

连接模型后，可以直接提问或说出想法。需要核对过去的表达时，助手会查找记录，并提供可打开的来源。
普通讨论不需要每次都搜索笔记。未连接模型时，页面会明确标示；仍可使用本地查找、规则对照与关系图。

## 核对回答

点击来源按钮，可看到引用的片段、原文位置及日期。最多并排阅读两条记录。
历史回答保留当时引用的片段；关系图展示当前索引中的记录，二者可能因笔记修改而不同。

## 由你确认的记忆

当助手提出可核对的观点比较时，可以选择“这贴近我的想法”“我想补充或修正”或“暂时放着”。
在“记忆”页可查看自己的判断、修改或撤回。普通对话中的一次表达不会自动成为永久标签。
撤回后，该判断不再用于新的记忆召回；既有对话仍然保留。

## 长对话

为了控制请求大小，较早的内容可能不再完整发送给模型；原始消息仍保存在历史中。
如果助手漏掉重要限定，可以补充或指出原话。压缩不代表助手记住了每一件事。

## 不同笔记库

每个笔记库分别保存对话、记忆和模型设置。切换笔记库后，可以从该库历史中继续之前的对话。
