# 聊天导入与外部服务注意事项

## 选择接入方式

已有导出文件或带日期、发言人的微信片段，可以直接在“导入”页预览，无需安装额外桥接工具。
QQ 服务连接是可选入口，需要自行运行兼容的 QQChatExporter 服务。Memory Garden 不捆绑、安装或启动第三方程序，也不代用户登录账号。

## 数据如何使用

- 预览和导入在本机处理，不调用生成模型。
- 确认本人身份与检索范围后，记录才会用于后续检索。
- 已开启云端生成、Embedding 或 Rerank 时，后续操作可能按相应配置发送内容。
- 导入副本、数据库和另存的 JSON 是本地明文文件，请自行保护和备份。
- 文件中的日期、姓名来自导出内容，需要自己核对。
- 停止检索保留副本和历史对话，不是彻底删除功能。

## 使用 QQ 服务连接

连接器只接受本机 HTTP 回环地址。输入服务地址和令牌后，选择好友或群聊，预览所选数量的近期文字。
令牌不保存到数据库或浏览器存储。附件不会自动下载，合并转发不会展开成当前发言人的原话。

第三方程序可能拥有比本应用连接器更广的权限，也可能预读更多消息。只填写本机地址，并不能保证第三方服务没有监听其他网络接口。
请从可信来源获取程序，自行核对版本、权限、访问口令和监听范围；使用后关闭不需要的服务。
开源或本地运行本身不等于安装包安全，版本差异也可能导致连接不可用。连接失败时可以改用已有文件导入。

## 微信支持范围

支持已有 TXT、Markdown、通用 JSON、ChatLab 和兼容的 Chatlog JSON 文件，也支持主动粘贴保留时间、发言人的片段。
当前不提供客户端密钥提取、数据库解密、扫码绑定或持续消息同步。文件导入能力不代表能够从客户端取得完整历史。

具体格式、大小限制和操作步骤见[聊天导入指南](CHAT_IMPORT.md)。
