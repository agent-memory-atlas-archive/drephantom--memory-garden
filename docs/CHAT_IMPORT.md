# 微信与 QQ 聊天导入

在导航中打开“导入”，默认使用“导入文件”，也可选择“粘贴微信片段”或可选的“连接 QQ 服务”。所有路径都先预览发言人和时间，
明确哪些身份是自己，再勾选同意加入 Agent 检索范围并导入。也可以明确选择全部作为他人引用。
预览不调用模型，不写入数据库；15 分钟后过期，最多同时保留 5 份预览。
单份文件最多 2 MiB、2,000 条消息，大型历史请按会话或日期分段导出。

原始 Vault 保持只读；导入副本存放在当前数据库旁的 `imports/`，按内容与身份选择去重。
未知发送者和未选择为本人的发送者均标为引用，不当作个人立场。
消息时间保留导出时间戳的含义，不推断其描述事件的实际发生日期。
图片、语音、视频或系统消息不做 OCR/转写，其可用性以预览警告为准。

预览与提交在本机处理。导入后，如果已连接云端生成、Embedding 或 Rerank 服务，
后续使用可能按对应配置发送相关内容；本地导入不意味着所有后续模型调用也在本地。
“停止检索此导入”关闭未来检索及关联记忆召回，保留本地副本和已有对话。
重新预览同一文件并确认导入可恢复检索；它不是完全删除功能。

## 连接本机 QQ

本项目没有内置、安装或运行 QQChatExporter。连接器已实现，真实账号联调尚未完成。
开源及本机运行不能证明外部客户端安全，当前固定源码存在需核对的默认配置风险；详见[聊天接入安全说明](CHAT_IMPORT_SAFETY.md)。

需要用户已运行 QQChatExporter（QCE）并登录 QQ。在本页填写它的本机服务地址
（通常为 `http://127.0.0.1:40653`）及访问令牌，选择好友或群聊，再选择最近 100、200 或 500 条。
Memory Garden 在本页显示文字预览，可另存为标准 JSON，或确认本人身份后直接加入记忆。
不需要先去其他页面手动导出文件。令牌只用于当次请求，不保存到数据库或浏览器存储。

这是本项目实现的本地 HTTP 连接器，客户端登录及历史读取由 QCE / NapCat 提供。
没有把第三方程序捆绑进应用，也没有实现自己的 QQ 协议或客户端数据库解密器。
只读取所选会话；QCE 的 fetch 接口本身可能预读并缓存额外多页消息，
我们接收和预览的条数受所选上限约束。因此此功能用于接入近期文字片段，不是完整备份。
分页会话列表只请求用户当前选择的好友或群聊类型。

生成的 JSON 保留消息 ID、发送者 ID、时间、纯文本及明确的回复 ID。
同名发言人按账号区分，引用预览与合并转发中的他人文字不展开为当前发言人的原话，
附件和卡片不会下载；预览提示本次未展开的内容。该 JSON 是规范化文本导出，不是客户端原数据库副本。
未找到可读文字、QCE 未登录或格式不匹配时明确提示，可切换到文件导入。

## 格式与适配

| 输入 | 当前支持 |
| --- | --- |
| 本机 QCE 服务 | 选择好友或群聊，读取最近最多 500 条中的文字，生成标准 JSON |
| QQ / 微信 TXT、Markdown | 可识别的时间与发送者记录，保留多行正文 |
| 普通 JSON 数组 | `sender`、`timestamp`、`text`，可带平台来源编号 |
| QQChatExporter JSON | 包含 `metadata`、`chatInfo`、`messages` 的单文件导出 |
| ChatLab JSON | 0.0.1 / 0.0.2 标准 |
| 微信 Chatlog JSON | 含完整 `seq/time/talker/sender/isSelf/type/subType/content` 等字段的原始消息数组；Chatlog Session 导出兼容 |

文件入口可选择 UTF-8、GB18030 或 UTF-16LE。
JSON 数组的消息应包含文本、发送者和可解析时间；未知结构明确报错，不猜测内容。
对 QQChatExporter、ChatLab 与微信 Chatlog 的专用 JSON 适配依据各自项目字段定义独立实现，
单文件导出为目标，分块清单、JSONL、压缩包、客户端加密数据库与媒体附件不在当前范围。
即使导出包含 `selfUid` 或 `ownerId`，仍由用户在预览中确认本人，防止错把别人的账号当成自己。
同名发言人用稳定 ID 区分。同一份原文重新确认本人身份时，旧的身份归属版本停止检索，
避免新旧版本同时被当作证据；副本、对话与反馈历史继续保留。

## 粘贴微信片段

无需安装外部导出程序。把已主动复制、保留发言人和完整日期时间的片段粘贴到文本框，预览后确认身份与检索范围。
输入仅留在当前页面；点击预览后由本机服务解析。只有正文、没有日期和发言人的剪贴板文本会明确拒绝，不凭当前时间或模型猜测补齐。
也可以粘贴已有的微信 Chatlog JSON。微信适配保留稳定发送者 ID、原始时区与来源行号；`isSelf` 不自动确认本人。
纯文字以外的引用、转发、图片等只保留类型占位，不读取嵌套引用或附件地址。原始导入副本仍保留，供核对省略部分。
这些路径处理的是用户提供的片段或文件，不直接读取微信客户端，也不能保证导出覆盖完整历史。
